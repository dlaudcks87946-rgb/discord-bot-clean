# 프로젝트 규칙 (Project Rules)

## 봇 재시작 및 배포 규칙 (Bot Restart & Deployment Rules)
코드를 수정하더라도 자동으로 커밋 및 푸시(재시작)를 수행하지 마십시오. 오직 **사용자가 명시적으로 봇 재시작 또는 배포를 요청할 때만** 아래 단계를 수행하여 변경사항을 반영하고 Railway 재시작을 트리거합니다.

1. **변경 사항 확인 및 스테이징**: `git status`로 변경 사항을 확인한 후, 수정한 코드 파일(예: `호야.py`)을 `git add` 명령어로 스테이징합니다.
2. **커밋 생성**: 변경 내역에 알맞은 메시지로 커밋을 생성합니다. (예: `git commit -m "chore: restart bot"`)
3. **원격 저장소 푸시**: `git push origin main`을 실행하여 원격 저장소에 코드를 푸시합니다. 이를 통해 Railway에서 새 빌드와 함께 봇의 자동 재시작이 트리거됩니다.
